# Ghostty Warm — VSCode Theme

Dark theme derived from a Ghostty terminal config. Cool dark background with a distinct color per token role.

## Palette

| Role | Color | Family |
|---|---|---|
| Background | `#21252C` | — |
| Foreground / variables | `#B0B0B4` | neutral |
| Comments | `#6B9DB8` | blue |
| Keywords | `#D4A017` | yellow |
| Strings | `#4EC9A8` | teal |
| Numbers & booleans | `#F7B485` | peach |
| User functions | `#B39DDB` | purple |
| Built-in functions | `#6DB87A` | green |
| Types & classes | `#5DADE2` | blue |
| Object properties | `#C4967A` | brown |
| Parameters | `#9ABCCC` italic | soft blue |
| String escapes / `${}` | `#6DB87A` | green |
| Punctuation | `#4A5260` | dim |

## Install

```sh
ln -s ~/Documents/shells/vscode-theme ~/.vscode/extensions/ghostty-warm
```

Cursor users: symlink into `~/.cursor/extensions/` instead.

Then: **Cmd+Shift+P → Color Theme → Ghostty Warm**

Reload after changes: **Cmd+Shift+P → Developer: Reload Window**
